TabBlocker, a Chrome extension to block tabs.

This extension allows you to temporarily block the current tab for an entered amount of time. You can have any
number of tabs blocked at once, and the timer does not reset when switching tabs or refreshing the page.

I wanted to make this extension for my own use and drew inspiration from the pomodoro technique, except
that I wanted more control over the timer.

To try this extension:
1) Download the repository and extract it.
2) Open Chrome and go to `chrome://extensions`.
3) Click "Load unpacked" and select the folder you extracted.

I am planning to add more features to this extension in the future. Some of the planned features include:
- Blocking all tabs that match the entered domain.
- Muting all sounds on the blocked tab.
